# Shared implementation contracts
Python >=3.10; package sage. Plain JSON dictionaries at module boundaries; pathlib paths. No large downloads locally. numpy/torch available locally. All files under this project.

Action: {id:uuid str, tool:str, args:dict, reason:str optional, expected:dict optional}. Tool names filesystem.list/read/write/mkdir, data.profile/query, code.run, calculator.eval, finish, inspect. Authority authorizes every tool request. Goal: {id, instruction, completion:dict, priority, max_actions, max_seconds, training_consent:bool, status, version}; completion {type:'artifact'|'answer', path?, contains?}. Runtime workspace is distinct from state and source.

Observation dict: {id,timestamp,source_env,episode_id,step,entities,observed_fields,missing_fields,evidence_class:'OBSERVED',provenance, schema_version:1}; components may accept flexible dict events.
Receipt: {id,action_id,status:'CONFIRMED_SUCCESS'|'CONFIRMED_FAILURE'|'BLOCKED'|'UNKNOWN', evidence:dict, elapsed:float, side_effects:list}. Execution evidence is observed, LLM output only inferred unless checked.

Training module public contracts (agent owns models.py, simulators.py, training.py, evaluation.py and associated tests):
`LearningSystem(state_dir, device='cpu')`; `.bootstrap(max_steps=120, seed=17)->dict` bounded/resumable train and return report; `.predict(history:list[dict], action:dict)->dict` fields success_probability, completion_probability, delay, uncertainty, changed_probability; `.policy_score(history,action)->float`; `.control(history)->dict` decision inspect/retrieve/act/stop plus scores; `.learn(experiences:list[dict],max_steps=20)->dict`; `.evaluate()->dict`; model schema accepts typed serialized state/action, no fixed simulator-only features. Save trained weights + optimizer + provenance. May extend interfaces with documented defaults. Module model checkpoints local small. Keep holdout distinct.

Authority module public contracts (agent owns authority.py, execution.py, sandbox.py and tests):
`AuthorityService(state_dir,workspace)`; `.create_goal(instruction, completion=None, max_actions=12, max_seconds=300, training_consent=False)->dict` owner API; `.grant(goal_id, tools=None)->dict` owner API returns signed grant; `.check(grant,action)->dict` dry run allow/reason; `.revoke(goal_id)->None`; `.goal(goal_id)->dict`; `.update_goal(goal_id,**changes)->dict`; `.execute(grant,action)->receipt`; `.close()`. Run service in separate process; cognitive caller receives only action API; model cannot run host Python or mint grants. Host UI keeps owner endpoint. Default tools reversible workspace ops only; no network/shell/credentials. Code execution OS isolation fail-closed. Recheck budget/grant each action. Idempotency, symlink/traversal defense. Data/query and calc useful actual operations. Document action schemas via `describe_tools()` exported execution.py. finish needn't dispatch.

Memory module public contracts (agent owns memory.py, persistence.py, improvement.py and tests):
`MemoryStore(state_dir)`; `.append(kind,payload,goal_id='',episode_id='',evidence_class='OBSERVED',provenance='live',training_consent=False)->str`; `.retrieve(query,scope='',limit=5)->list[dict]`; `.claim(text,evidence_ids,contradictions=None,supersedes=None)->str`; `.register_skill(skill:dict)->str`; `.skills(query='')->list`; `.training_experiences(limit=256)->list`; `.events(goal_id='',limit=50)->list`; `.close()`. scope filters must precede ranking. persistent sqlite + vector hashing baseline, optional pretrained encoder integration if practical. User delete API, no false truth.
`DrivePersistence(local_dir,drive_dir)`; `.restore()->dict`; `.sync()->dict` atomic versioned snapshots with integrity validation, sqlite online backup; must not overwrite source/workspace unexpectedly. `.restore` only on empty state or safe explicit option.
`ImprovementManager(state_dir)`; `.propose(failures:list)->dict`; `.run(candidate:dict)->dict` isolated bounded config experiments (no arbitrary host execution); `.promote(candidate_id, approved=False)->dict` explicit owner only, passing independent eval and integrity; `.rollback(approved=False)->dict`. Config variants consumed by root planner if active config available. Document final contracts promptly.

Root owns llm.py, agent.py, colab.py, ui.py, cli.py, schema.py, documentation/build notebook, integration tests. Others do not edit those. No git mutations.
